# 신규 영업사원 자동 반영

## 문제

- 최신 Tableau 부킹 원본에는 `TOMHUANG`이 상해 담당자로 존재했지만, 2026-05-19 기준 `salesman.csv`에는 없었다.
- 기존 로직은 고객 코드의 현재 담당자 매핑을 우선하여 신규 ID를 기존 담당자로 덮어썼다.
- 일부 고객 코드가 없는 54건만 `TOMHUANG`으로 남았고, OBT 영업사원별 표에서는 `obt_salesmen` 목록에 없어 제외됐다.

## 변경

- 최근 45일 출항 기준으로 3건 이상 확인되는 단일 영업사원 ID를 신규 후보로 자동 감지한다.
- 쉼표로 연결된 복수 담당자 문자열은 신규 ID로 인정하지 않는다.
- 기존 `salesman.csv`에 등록된 ID는 계속 현재 고객 담당자 매핑을 우선한다.
- 신규 후보는 원시 부킹의 `Salesman_POR`를 보존하고, 비 KR/JP 선적지 후보는 OBT 영업사원 목록에 포함한다.
- 일일 후처리와 Sales Target 데이터 빌더에서도 신규 후보를 다시 기존 담당자로 덮어쓰지 않는다.
- Sales Target의 `Summary_All` 허용 목록에 없는 신규 후보도 실적용 임시 행으로 추가한다.
  - 목표는 미배정 상태(`-`)로 표시한다.
  - 최근 실적과 상세 부킹 chunk는 정상 표시한다.

## 검증

- 원시 `2.csv`: `TOMHUANG` 3,145건, 이 중 상해 3,144건.
- 최종 대시보드 스냅샷: `TOMHUANG` 2,288건, 상해 2,287건, WOS-3 972건.
- `dist/data.json`: `provisional_salesmen` 및 `obt_salesmen`에 `TOMHUANG` 포함.
- 신규 감지·기존 담당자 우선·과거 ID 제외·후처리 보존 단위 테스트 통과.
